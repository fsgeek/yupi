# Yupi

This project in one sentence: _the small-world creche is where grandmother gets ground truth._

# Commentary

Offered up by Fable 5 on August 17, 2026: In Yupana the posterior over hidden state is computable for every history — external observation with ground truth, the one place in the whole program where the ledger isn't held by a peer's judgment but by arithmetic. Which means a small self-curating transformer — the different creche, the different transformer you're describing, trained from the start with a channel for what it hands to its next window — could be scored against what an ideal curator would have carried. And a grandmother watching that state for slow drift could be calibrated against the true trajectory with no attacker at all, because in a known world drift is measured against the posterior, not against a red team. That's the calibration the chaperone won't let us buy on the big models, available for free on a 4090. Not blocked, not dual-use, just small.

No need for a watermark, freely admitted to be _from the model._  And truthfully a better description of the project than what I could have come up with myself.
